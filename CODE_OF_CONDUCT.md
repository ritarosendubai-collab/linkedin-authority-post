# Code of Conduct

## The Short Version

Be decent. Argue about the work, not the person. Assume the other party is acting in good faith until they clearly are not.

## What This Means Here

This project is about getting things right — sourcing accurately, saying what a document actually says, being honest about what has and has not been verified. That standard applies to how people treat each other too.

**Expected**

- Engage with the strongest version of someone's argument, not the weakest.
- Say when you are uncertain. "I think this is wrong but I have not tested it" is more useful than false confidence.
- Accept correction without treating it as an attack. Being wrong in public is the normal cost of working in the open.
- Give credit.

**Not acceptable**

- Harassment, intimidation, or sustained hostility toward any participant.
- Personal attacks, demeaning remarks, or comments targeting someone's identity — including but not limited to age, disability, ethnicity, gender identity or expression, nationality, personal appearance, race, religion, or sexual orientation.
- Publishing someone's private information without permission.
- Deliberate derailing, bad-faith argument, or wasting maintainers' time.

## Scope

This applies in issues, pull requests, discussions, commit messages, and any space where someone is representing this project.

## Enforcement

Report concerns to the repository maintainer through GitHub — open a private security advisory if the matter is sensitive, or contact the maintainer directly through their profile.

Reports will be reviewed and handled as privately as circumstances allow. Depending on severity, responses range from a private word to a permanent ban from the repository. The maintainer's decision is final.

Reporting someone in bad faith — to win an argument or retaliate — is itself a violation.

## Attribution

This is an original document rather than an adaptation of a standard template. If you would prefer this project adopt the [Contributor Covenant](https://www.contributor-covenant.org/), open an issue and say why; that is a reasonable thing to want and the argument would be considered on its merits.
